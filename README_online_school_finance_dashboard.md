# Online School Finance Dashboard Case

Универсальный демонстрационный кейс системы бюджетирования, финансового контроля и анализа для онлайн-школы.

## Внутри

- панель руководителя
- бюджет и план-факт
- скользящий прогноз
- ОПиУ, ДДС и управленческий баланс
- интерактивная финансовая модель
- дерево финансовых метрик
- казначейство и платежный календарь
- контроль качества данных
- светлая и темная темы

Все данные в прототипе синтетические и используются исключительно для демонстрации архитектуры управленческой системы.

## GitHub Pages

Для публикации переименуйте `github_pages_index.html` в `index.html`, разместите его в корне репозитория и включите GitHub Pages для ветки `main`, папка `/(root)`.
