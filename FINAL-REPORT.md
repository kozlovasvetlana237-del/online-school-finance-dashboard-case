# Итоговый отчёт по финансовой системе онлайн-школы

## Результат

Интерактивная демонстрационная финансовая система опубликована на GitHub Pages:

https://kozlovasvetlana237-del.github.io/online-school-finance-dashboard-case/

Все данные синтетические и используются только для иллюстрации финансовой логики.

## Архитектура

- `data/demo-data.js` - единая модель периодов, продаж, расходов, бюджетов, клиентов, когорт и денежных операций.
- `js/financial-engine.js` - ОПиУ, ДДС, баланс, признание выручки и rolling forecast.
- `js/analytics.js` - план-факт, факторные мосты, сигналы, юнит-экономика, когорты, казначейство и бюджетный контроль.
- `js/ui-state.js` - фильтры, тема, пользовательские настройки и перенос даты платежа.
- `js/ui.js` - рендеринг интерфейса и обработчики управления.
- `tests/` - автоматические проверки финансовой модели, данных и UI-контрактов.

## Реализованные функции

- панель CFO с выручкой, EBITDA, денежным потоком и исполнением бюджета;
- план-факт и факторные мосты выручки и EBITDA;
- rolling forecast на 12 месяцев и сценарии;
- юнит-экономика и когортный анализ;
- платёжный календарь на 30, 60 и 90 дней;
- бюджетный контроль с локальным редактированием статусов;
- фильтры периода, сценария, продукта, подразделения и режима данных;
- пользовательский сценарий с сохранением в localStorage;
- CAC, LTV/CAC и доля возвратов;
- перенос условной даты платежа с пересчётом ликвидности;
- светлая и тёмная темы.

## Исправленные ошибки

1. Независимые расчёты основных KPI заменены единой финансовой моделью.
2. Конечный денежный остаток связан с начальным остатком и чистым денежным потоком.
3. План-факт и факторные мосты проверяются математическими тестами.
4. Причины сигналов не выдумываются при отсутствии подтверждённых данных.
5. Кассовый разрыв определяется расчётом по ежедневному календарю.
6. Исправлено кэширование модульных импортов GitHub Pages.

## Тесты

Команда `npm test` проходит успешно: 30 тестов, 0 ошибок.

Проверены финансовые равенства, предоплаты, возвраты, рассрочки, чувствительность EBITDA, факторные мосты, rolling forecast, CAC, когорты, ликвидность, бюджетный контроль, фильтры и UI-контракт.

## Ограничения

- данные синтетические;
- пользовательские настройки хранятся только в браузере;
- корпоративного workflow согласования нет;
- сравнение и режим план / факт / прогноз представлены в интерфейсе демо-версии, но требуют дальнейшего расширения расчётов для полного сквозного влияния на каждый экран;
- браузерная проверка выполнена как smoke-тест, отдельного CI-браузерного теста нет.

## Запуск

```text
npm test
```

Для локального просмотра достаточно открыть `index.html` через локальный HTTP-сервер. Публикация выполняется через ветку `main` и GitHub Pages.
