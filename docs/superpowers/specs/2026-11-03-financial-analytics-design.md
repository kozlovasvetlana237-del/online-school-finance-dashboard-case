# Управленческая аналитика этапа 2

Дата: 2026-11-03

## Цель

Добавить к финансовому ядру план-факт анализ, факторные мосты, rolling forecast на 12 месяцев и управленческие сигналы. Все показатели должны рассчитываться из единой модели этапа 1.

## Ветка и границы

Работа выполняется в ветке codex/financial-analytics, основанной на codex/financial-core. Целевой PR этапа 2 должен направляться в codex/financial-core, чтобы не смешивать незавершённые этапы.

В этап 2 входят:

- план-факт по выручке, себестоимости, маркетингу, ФОТ, административным расходам и EBITDA;
- детализация бюджетных статей;
- факторный мост выручки;
- отдельный мост EBITDA;
- rolling forecast на 12 месяцев;
- базовый, оптимистичный, консервативный и пользовательский сценарии;
- управленческие сигналы с настраиваемыми порогами.

Юнит-экономика, когорты, казначейский календарь и бюджетный контроль остаются за пределами этапа 2.

## План-факт

Для каждой статьи рассчитываются:

- план;
- факт;
- абсолютное отклонение actual - plan;
- относительное отклонение;
- благоприятность с учётом типа статьи.

Для доходов рост относительно плана благоприятен. Для расходов рост относительно плана неблагоприятен. При нулевом плане относительное отклонение равно null и отображается как н/д.

План и факт агрегируются из budgets, sales, expenses и денежных операций. KPI не формируются из коэффициентов интерфейса.

## Факторный анализ выручки

Для новых продаж используется формула:

revenue = leads * conversion * averageCheck

Вклад факторов рассчитывается методом последовательных подстановок в фиксированном порядке:

1. лиды;
2. конверсия;
3. средний чек.

Для каждого фактора вычисляется разница между результатом после подстановки текущего значения и предыдущим результатом. Сумма вкладов равна итоговому отклонению выручки с учётом округления.

Повторные продажи и признание выручки по оказанным услугам не объясняются только текущими лидами. Они остаются отдельными компонентами расчётной модели.

## Факторный анализ EBITDA

Мост EBITDA включает:

- отклонение признанной выручки;
- отклонение себестоимости;
- отклонение маркетинга;
- отклонение ФОТ;
- отклонение прочих операционных расходов.

Знак каждого фактора определяется влиянием на EBITDA. Сумма факторов должна точно равняться отклонению EBITDA.

## Rolling forecast

Forecast содержит 12 последовательных месяцев. Для каждого месяца отображается:

- закрытый факт или прогноз;
- утверждённый бюджет;
- предыдущая версия прогноза;
- текущая версия прогноза.

Последний закрытый месяц выбирается пользователем. Закрытые месяцы не пересчитываются сценарными драйверами. Незакрытые месяцы рассчитываются из драйверов модели.

Сценарии:

- базовый;
- оптимистичный;
- консервативный;
- пользовательский.

Изменяемые драйверы:

- лиды;
- конверсия;
- средний чек;
- возвраты;
- маркетинговые расходы;
- прямые затраты;
- ФОТ;
- административные расходы.

Вероятность исполнения плана не показывается, если в данных нет статистической базы. Вместо этого отображается диапазон сценариев и абсолютное отклонение к бюджету.

## Управленческие сигналы

Сигнал создаётся только при выполнении проверяемого правила. Каждый сигнал содержит:

- проблему;
- числовое основание;
- причину только при наличии подтверждающих данных;
- возможное последствие;
- действие;
- ответственного;
- статус.

Если причина не подтверждается данными, показывается статус требует анализа. Пороговые значения хранятся в конфигурации и могут изменяться в демо-режиме.

Примеры правил:

- превышение бюджета маркетинга;
- снижение EBITDA margin ниже порога;
- снижение прогноза выручки относительно бюджета;
- рост возвратов выше порога;
- отрицательное отклонение операционного денежного потока;
- отсутствие данных для объяснения отклонения.

## Тестирование

Добавляются проверки:

- сумма план-факт факторов равна отклонению;
- мост EBITDA сходится;
- изменение каждого драйвера изменяет только зависимые расчёты;
- факт закрытых месяцев не меняется при сценарном пересчёте;
- все 12 месяцев rolling forecast идут последовательно;
- нулевые планы и пустые периоды возвращают н/д;
- сигналы не придумывают причины без подтверждённых данных;
- сценарии не используют неподтверждённые вероятности.

## Критерии готовности

- план-факт строится из единой модели;
- факторные мосты математически сходятся;
- rolling forecast отображает 12 последовательных месяцев;
- сценарии пересчитывают прогнозные финансовые показатели;
- сигналы имеют числовые основания и настраиваемые пороги;
- критические тесты проходят;
- ограничения этапа 2 описаны в отчёте;
- PR направлен из codex/financial-analytics в codex/financial-core.
